# FMO Companion 原型覆盖矩阵

## 使用方式

本矩阵把产品规格映射到 HTML 原型入口、可评审交互和后续正式开发重点。原型用于验证信息架构、任务流程、状态和文案，不代表已经实现真实网络、密码学、位置、存储或系统集成。

覆盖等级：

- **主流程：** 可从入口完成代表性任务，并看到处理中与结果状态。
- **状态模型：** 可查看核心数据和主要状态，部分操作使用模拟反馈。
- **信息架构：** 已确定入口与信息层级，正式系统交互仍需开发验证。

## SPEC 覆盖

| 规格 | 原型入口 | 覆盖等级 | 可评审交互 | 正式开发重点 |
|---|---|---|---|---|
| SPEC-001 发现 FMO | 首页 → 开始发现 / 手动输入 | 主流程 | 等待、发现结果、停止、手动主机回退 | Bonjour、10 秒超时、本地网络权限、端点持久化 |
| SPEC-002 连接诊断 | 首页 → 连接诊断 | 主流程 | Wi-Fi、解析、HTTP、WebSocket 分层结果 | 类型化错误、脱敏报告、系统设置入口 |
| SPEC-003 坐标读写 | 首页 → 连接 → 坐标同步 | 主流程 | 读取盒子坐标、展示手机坐标、同步进度和成功结果 | WebSocket 状态机、范围校验、5 秒超时、取消 |
| SPEC-004 后台位置 | 首页 → 位置自动化 | 主流程 | 三种模式、时间/距离阈值、授权、断线暂停与恢复 | 固定正式预设、Core Location 事件驱动、始终授权、退避与耗电测试 |
| SPEC-005 官方 Web | 首页 → 打开官方页面 | 主流程 | 后台与 QSO 页面入口；原型浏览方式选择不进入正式 App | `SFSafariViewController`、稳定端点 URL 构造与不可达错误 |
| SPEC-006 地图与目录 | 网络 → 地图 / 台站与服务器目录 | 状态模型 | 地图、搜索、台站/服务器/收藏、数据年龄 | APRS 传输、地图聚合、搜索索引、收藏持久化 |
| SPEC-007 事件与通知 | 网络 → 完整事件流；设置 → 通知 | 主流程 | CQ、OMCQ、VOCAL、ONLINE、BEACON、STATION、JOINT/EVENT 和过滤 | 事件解析、通知架构 ADR、距离与收藏过滤 |
| SPEC-008 身份验证 | FMO 网络 → 台站详情 → 验证详情 | 状态模型 | CERT、呼号、证书链、CRL、签名、timeSalt、哈希关系与异常分类 | 确定性 CBOR、Ed25519、CRL 更新、可信状态策略 |
| SPEC-009 APRS 短消息 | FMO 网络 → 消息与通讯 | 主流程 | 呼号/SSID/Keychain、发送、等待 ACK、已 ACK | APRS-IS 会话、Keychain、消息去重、ACK 超时与重试 |
| SPEC-010 远程控制 | 首页 → 更多设备功能 → 远程控制 | 主流程 | Time Slot、Counter、HMAC 阶段、ACK、生物认证确认 | Counter 原子持久化、HMAC、LocalAuthentication、重放保护 |
| SPEC-011 QSO | QSO → 导入 / 查询与详情 / ADIF 导出 | 主流程 | Schema、SHA-256、P-256、进度、查询、地图、APP_FMO 字段 | 安全文件访问、SQLite 只读、可取消索引、系统分享 |
| SPEC-012 服务器运维 | 设置 → 管理员功能 → 管理员写操作 | 主流程 | HTTPS 状态、DNS/MQTT/EMQX/SAS、资源、广播、日志、二次确认 | 独立认证 API、脱敏、短时令牌、权限分级、告警阈值 |
| SPEC-013 iOS 集成 | 设置 → 通知 / 小组件与快捷指令 / 隐私与无障碍 | 信息架构 | 通知规则、桌面/锁屏 Widget、快捷指令、深色模式、Dynamic Type | APNs、WidgetKit、App Intents、String Catalog、VoiceOver |

## 原型与 AI 说明规则

- 手机内用户层只保留首页、FMO 网络、QSO、设置四个标签。
- HTML 只展示最终用户界面，不提供规格跳转或评审面板。
- 规格编号、里程碑、状态分支与实现约束记录在本文和 `docs/design/prototype-implementation-guide.md`。
- 未配置 APRS 或自建服务器时，对应高级入口应按上下文隐藏或降级提示。

## 持续边界

“设置 → 关于与产品边界”明确展示以下排除项：

- 不解码或收发未公开 MQTT 语音。
- 不抓包、逆向固件或模拟 FMO 设备身份。
- 不获取、导出、复制或使用盒子私钥。
- 不原生映射未公开设置、OTA、激活或证书签发。
- 真机验证前不保证 iPhone 个人热点反向访问。

## 原型共用规则

- 所有设备、呼号、服务器、坐标、消息和 QSO 都是虚构数据。
- 所有网络、位置、Keychain、Face ID、文件、通知和导出操作均为前端模拟。
- 后续开发不得复制原型中的定时器作为正式超时、调度或网络实现。
- 每个正式功能仍需按对应规格补充单元测试、UI/集成测试和真机验收。
