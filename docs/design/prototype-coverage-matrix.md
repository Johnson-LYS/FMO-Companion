# FMO Companion 原型覆盖矩阵

## 使用方式

本矩阵把产品规格映射到 HTML 原型入口、可评审交互和后续正式开发重点。原型用于验证信息架构、任务流程、状态和文案，不代表已经实现真实网络、密码学、位置、存储或系统集成。

覆盖等级：

- **主流程：** 可从入口完成代表性任务，并看到处理中与结果状态。
- **状态模型：** 可查看核心数据和主要状态，部分操作使用模拟反馈。
- **信息架构：** 已确定入口与信息层级，正式系统交互仍需开发验证。

## SPEC 覆盖

| 规格 | 原型入口 | 覆盖等级 | 可评审交互 | 正式开发重点 |
|---|---|---|---|---|
| SPEC-001 发现 FMO | App 启动 → 恢复上次设备；设备状态卡 → 设备选择 Sheet | 主流程 | 启动扫描、上次设备优先连接、抽屉内增量结果/停止扫描/手动切换/手动主机回退；无主动断开入口 | Bonjour、10 秒超时、单扫描/单连接任务、本地网络权限、稳定端点持久化与切换隔离 |
| SPEC-002 连接诊断 | 设备 → 连接诊断 | 主流程 | Wi-Fi、解析、HTTP、WebSocket 分层结果 | 类型化错误、脱敏报告、系统设置入口 |
| SPEC-003 坐标读写 | 设备 → 连接 → 坐标同步 | 主流程 | 读取盒子坐标、展示手机坐标、同步进度和成功结果 | WebSocket 状态机、范围校验、5 秒超时、取消 |
| SPEC-004 后台位置 | 设备 → 位置自动化 | 主流程 | 三种模式、时间/距离阈值、授权、断线暂停与恢复 | 固定正式预设、Core Location 事件驱动、始终授权、退避与耗电测试 |

| SPEC-014 设备仪表盘 | 设备 → 连接 → 顶部仪表盘 | 主流程 | 大字号呼号、同一行设备选择按钮、六位梅登黑德、过滤距离、当前服务器、单行本地讲话/历史；频率与 QSO 数不进入设备卡 | ADR-0005 已批准并实现只读数据层；实时活动从 0.3 延期，已有 ActivityKit 探索实现仅作 checkpoint |

| SPEC-007 事件与通知 | 网络 → 最近动态 / 完整事件流；设置 → 通知 | 主流程 | CQ、OMCQ、图标化 VOCAL、ONLINE、BEACON、STATION、JOINT/EVENT、收藏过滤与 `24h · 200` 保留提示 | 事件解析、24 小时/200 条双重上限、近期语音 TTL、通知架构 ADR、距离与收藏匹配 |

| SPEC-009 APRS 短消息 | FMO 网络 → 消息 → 新消息 / 会话；APRS 身份 Sheet | 主流程 | 前台状态、最近会话、收藏/手动收件人、本地历史、发送、等待 ACK、已确认/未确认、左滑删除；身份只编辑呼号/SSID | 隔离写会话、基础呼号 PASSCODE 按需计算、SwiftData、去重、ACK 精确关联、有限重试与生命周期取消 |
| SPEC-010 远程控制 | 设备 → 更多设备功能 → 远程控制 → 远控设置 | 主流程 | 目标 FMO、按设备配置 SECRET、NORMAL/STANDBY/REBOOT、产品化发送结果、危险确认与生物认证说明 | 官方固定向量、目标 SECRET、Counter 原子持久化、HMAC、LocalAuthentication、禁止自动重试 |
| SPEC-011 QSO | QSO → 导入 / 查询与详情 / ADIF 导出 | 主流程 | Schema、SHA-256、P-256、进度、查询、地图、APP_FMO 字段 | 安全文件访问、SQLite 只读、可取消索引、系统分享 |

## 原型与 AI 说明规则

- 手机内用户层只保留设备、FMO 网络、QSO、设置四个标签。
- HTML 只展示最终用户界面，不提供规格跳转或评审面板。
- 规格编号、里程碑、状态分支与实现约束记录在本文和 `docs/design/prototype-implementation-guide.md`。
- 未配置 APRS 或自建服务器时，对应高级入口应按上下文隐藏或降级提示。

## 持续边界

“设置 → 关于与产品边界”明确展示以下排除项：

- 不解码或收发未公开 MQTT 语音。
- 不抓包、逆向固件或模拟 FMO 设备身份。
- 不获取、导出、复制或使用盒子私钥。
- 不原生映射未公开设置、OTA、激活或证书签发。
- 真机验证前不保证 iPhone 个人热点反向访问。

## 原型共用规则

- 所有设备、呼号、服务器、坐标、消息和 QSO 都是虚构数据。
- 所有网络、位置、Keychain、Face ID、文件、通知和导出操作均为前端模拟。
- 后续开发不得复制原型中的定时器作为正式超时、调度或网络实现。
- 每个正式功能仍需按对应规格补充单元测试、UI/集成测试和真机验收。
