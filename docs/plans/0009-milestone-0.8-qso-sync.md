# 计划 0009：0.8 QSO 自动同步

## 目标

让用户连接自己的 FMO 后无需下载或导入文件，即可在 QSO 标签查看盒子日志、离线浏览最近同步内容、搜索和查看网格地图，并导出标准 ADIF。只有自动同步成立，0.8 才保留。

## 已冻结产品范围

- 当前所选 FMO 是 QSO 的活动来源；切换设备后切换到对应设备缓存，不把多台盒子日志静默混合。
- 设备连接/切换、App 进入前台、QSO 页面出现时自动同步；页面可见期间低频检查，用户可手动刷新。不承诺后台实时或固定周期。
- 先展示分页摘要，最近记录优先补齐详情；旧详情在打开或 ADIF 导出时按需补齐。
- 离线时展示该设备最后一次完整成功同步的缓存和时间；部分失败不删除缓存。
- 列表与详情只显示实际字段，不显示“已验证/待检查”、SQLite、WebSocket、SHA-256 或 P-256 等实现文案。
- 地图按双方 Maidenhead 网格表达大致区域；ADIF 从 App 规范化缓存生成。

## 明确排除

- QSO 删除、恢复、清空、重新发起 QSO、设备端 ADIF/备份触发和签名密钥管理。
- 自动下载 SQLite、自动调用 POST 导出、把逐条同步记录冒充签名数据库快照。
- 后台持续同步、固定周期、通知推送、云同步和跨设备合并。
- DOM 注入、Cookie 复制、任意 `/ws` 命令代理、原始帧/QSO 内容日志。
- 以网格中心冒充精确坐标、通联轨迹或接口没有提供的通联时长。

## 接口与数据边界

- 只使用 ADR-0007：`qso/getList(page,pageSize)` 与 `qso/getDetail(logId)`。
- 列表负载固定为 `data.list`，摘要字段为 `logId/timestamp/toCallsign/grid`；详情负载固定为 `data.log`，字段为 `fromCallsign/toCallsign/fromGrid/toGrid/freqHz/mode/relayName/relayAdmin/toComment/timestamp`。
- `/ws` 没有请求 ID：独立 QSO 会话内严格串行；切换设备、进入后台或取消时隔离迟到响应，页面离开后停止轮询并在空闲时关闭会话。
- 缓存键为 `DeviceStableID + logId`，同时比较摘要指纹；不假定 logId 跨清空或固件永久唯一。
- 只有同一会话全部摘要页成功后执行删除对账；中断时仅合并已确认的新值。

## 完成定义

- 用户只需连接自己的 FMO，QSO 标签即可自动出现盒子日志，无需理解或操作 SQLite。
- 新记录在 App 前台、QSO 页面可见时通过自动检查出现；离线、部分失败或设备切换不会混淆、丢失或错误删除缓存。
- 所有展示字段可追溯到 ADR-0007 schema；不虚构时长、精确位置或签名信任。
- 客户端在类型层面无法调用 QSO 管理/写操作，真实 QSO 不进入日志、fixture、文档或诊断。
- 查询、地图、ADIF、可访问性、自动化测试和真机闭环与已确认原型一致。
