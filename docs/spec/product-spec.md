# 产品规格

## 发布标识

- 中文显示名采用“FMO 助手”，避免与已有硬件产品“FMO 伴侣”混淆；“FMO 手机伴侣”可作为 App Store 中文副标题候选。
- 英文产品与文档名继续使用 “FMO Companion”。
- App 首版支持简体中文与英语，默认跟随 iOS 系统或系统中的单 App 语言设置；不在 App 内重复提供语言开关。未支持的系统语言回退英语。
- App Bundle ID 为 `com.bi8syn.fmoassistant`；测试 Target 与保留的实时活动 Target 使用同一命名空间下的后缀。
- App Icon 使用无预制圆角、全幅不透明的 1024 × 1024 主图；系统负责最终蒙版，未提供的外观变体由系统生成。
- App Store 主分类采用“工具”（Utilities）；副分类可采用“导航”（Navigation），不将 App 归类为社交网络或娱乐。
- App 仅调用 Apple 操作系统提供的 CryptoKit（Ed25519 数字签名验证、SHA-256）与 URLSession HTTPS/TLS，不实现自研或随 App 分发的第三方密码算法；`ITSAppUsesNonExemptEncryption` 为 `NO`，无需提交非豁免加密文稿。

## 首版设置与隐私政策

- Release 设置页只展示已经可用的真实功能，不出现管理员功能、通知、系统集成、快捷指令、小组件、实时活动、诊断导出或其他未来占位入口。
- 外观提供跟随系统、浅色和深色三种真实选项，选择立即作用于整个 App 并持久化。
- 隐私区提供隐私政策和 iOS 系统权限入口。公网政策尚未配置时，开发构建展示内容一致的 App 内政策页；正式发布前必须配置稳定的 HTTPS 地址，并与 App Store Connect 保持一致。
- 关于页展示产品名称、简短介绍、从 Bundle 动态读取的版本与构建号、开发者呼号 `BI8SYN` 和可点击邮箱 `BI8SYN@163.com`；不展示 Swift、SwiftUI、iOS 技术基线、协议栈或其他实现细节。
- 隐私政策以无 JavaScript、Cookie、分析、第三方字体或 CDN 的静态页面交付，准确说明本地网络、位置、APRS 公网传输、本地消息/QSO 缓存、Keychain SECRET、系统认证、数据删除与第三方网络边界。
- App、实时活动、权限用途说明、错误/状态与辅助功能文案均提供简体中文和英语；呼号、SSID、梅登黑德网格、IP、APRS/QSO 协议字段等用户数据不翻译。日期、数字和显示单位按系统区域格式化。
- 公网隐私政策在同一稳定 URL 同时提供完整中文和英文正文，使用页内语言锚点切换阅读位置，不依赖脚本、Cookie 或浏览器存储。

## 愿景

让 iPhone 成为 FMO 盒子的可靠原生伴侣：在局域网内自动发现设备、同步位置并按用户选择监听设备接收音频，在互联网侧安全查看 FMO/APRS 网络、发送标准消息与远控命令、管理通联日志和自建服务器，同时保持设备身份与音频数据的安全边界。

## 用户画像

- **主要用户：** 已取得业余无线电操作证、呼号，并持有已激活 FMO 盒子的 iPhone 用户。
- **服务器管理员：** 自行部署 EMQX 与 FMO SAS，希望移动查看服务状态的用户。
- **移动/车载用户：** 将手机与 FMO 接入同一普通 Wi-Fi 或便携路由器，需要持续同步位置的用户。

## 功能需求

### 局域网设备

#### SPEC-001：发现 FMO 盒子

**优先级：** Must
**状态：** Approved

App 启动后应自动使用 Bonjour 浏览 `_http._tcp.local.`，识别 FMO 服务并解析可连接地址，同时保存完整的已知设备列表。启动时按“上次成功设备、其余已保存设备、新发现设备”的稳定顺序串行尝试连接，并提供手动主机名/IP 作为回退。

**验收标准：**

- [x] 同一普通 Wi-Fi 中存在 FMO 时，用户可在 10 秒内看到发现结果或明确的超时状态。
- [x] App 启动即开始扫描，并同时从完整已知设备列表建立自动连接队列；上次成功设备排第一，其余设备保持稳定顺序。
- [x] 自动连接按队列串行尝试；单台失败不逐条打断用户，队列和本轮扫描均结束且仍未连接时才显示总体失败。
- [x] 扫描到的新设备去重后追加到列表和当前自动队列；若旧队列已经失败耗尽，则立即继续尝试新设备。
- [x] 已有连接时再次扫描只增量合并设备列表，不中断或自动切换当前设备。
- [x] 自动发现失败时，用户可输入 `fmo.local` 或 IPv4 地址继续。
- [x] App 记住完整设备列表和最后一次成功连接的稳定端点；成功设备移到列表首位，但不保存 Wi-Fi 密码或易变的作用域地址。
- [x] 再次自动发现时，App 保留用户手动输入和已经保存的端点，并按稳定的主机与端口身份去重。
- [x] 用户可从选择 Sheet 左滑立即移除设备，不增加二次确认；若移除当前设备，App 同时断开并清除对应记录，且不自动接管到下一台。仍在附近的设备可在后续发现中重新出现。
- [x] 设备页不常驻设备列表，也不提供可见或无障碍“断开连接”操作；呼号同一行的设备按钮打开选择 Sheet。点击当前设备不重连，点击其他设备切换目标，停止扫描不影响已有连接。
- [x] 用户手动选择设备时取消尚未完成的自动队列并立即优先连接该设备；成功后后续发现只追加列表，不自动切换。
- [x] 本地网络权限被拒绝时，App 解释原因并提供系统设置入口。

#### SPEC-002：连接诊断

**优先级：** Must
**状态：** Approved

App 应分别诊断主机解析、HTTP 后台和 GEO WebSocket，并显示可行动的错误。

**验收标准：**

- [x] 用户能区分未连接 Wi-Fi、无法解析主机、HTTP 不可达、WebSocket 握手失败和响应超时。
- [x] 诊断明确区分 App 当前会话连接状态与独立可达性探测；探测全部通过不得被表述为设备页已建立连接。
- [x] 诊断报告默认脱敏，不包含精确位置、PASSCODE、SECRET 或服务器令牌。

#### SPEC-003：读取与写入坐标

**优先级：** Must
**状态：** Approved

App 应通过 `ws://<host>/ws` 实现 `getCordinate` 与 `setCordinate`，保留协议历史拼写。

**验收标准：**

- [x] 能解析 `getCordinateResponse` 并显示盒子坐标。
- [x] 能获取 iPhone WGS84 坐标并发送 `setCordinate`。
- [x] 经度、纬度越界时在发送前拒绝。
- [x] 成功、设备拒绝、连接错误和 5 秒响应超时具有不同结果。

#### SPEC-004：后台位置同步

**优先级：** Must
**状态：** Approved

App 应提供手动、低功耗和车载定位模式。后台发送由 Core Location 事件触发，再应用时间与距离阈值，不承诺严格周期。

**验收标准：**

- [x] 手动模式不响应后台位置事件自动发送，只在用户显式操作时执行一次坐标同步。
- [x] 低功耗模式采用固定预设：首次有效位置事件立即同步；后续相对最后一次成功同步达到 15 分钟或移动 1 公里时同步。
- [x] 车载模式采用固定预设：首次有效位置事件立即同步；后续相对最后一次成功同步达到 2 分钟或移动 250 米时同步。
- [x] 时间与距离为“或”关系，只用于筛选系统已交付的位置事件；App 不使用自建定时器承诺严格周期。
- [x] 用户明确选择模式并在申请权限前理解功耗差异；0.2 不提供自定义阈值。
- [x] 手动模式只需使用期间定位权限；自动模式需要始终定位权限，权限不足时不得显示为正在后台运行，并提供恢复路径。
- [x] 自动模式始终提供可见的停止开关；停止、模式切换或权限失效会取消定位、退避、连接和发送任务。
- [x] App 离开盒子局域网后暂停连接和发送，不进行高频失败重试；离网期间只在内存中覆盖保留最新有效位置，不持久化精确坐标。
- [x] 用户未主动停止且权限仍满足时，恢复局域网后 App 重新连接并立即尝试发送最新有效位置；App 重启后等待新的有效位置事件。
- [x] App 持久化用户选择的模式，但不持久化精确坐标；系统允许后台重新启动时恢复相应定位会话。
- [x] App 分别显示后台定位授权、运行/暂停原因、最后一次尝试及最后一次成功，不把失败表述为已同步。

#### SPEC-005：官方 Web 后台入口

**优先级：** Should
**状态：** Approved

App 应使用系统标准 `SFSafariViewController` 打开所选盒子的官方后台及 QSO 页面，不注入脚本模拟未公开接口。

**验收标准：**

- [x] “管理后台”使用所选设备的稳定 HTTP 端点打开 `/`，“QSO 页面”打开 `/qso.html`。
- [x] 未选择设备、端点无效或页面不可达时显示可行动错误，不构造或加载任意外部地址。
- [x] App 不注入 JavaScript、不读取或模拟 DOM；本地原生能力只允许 ADR-0005/0007 固定的用户授权只读白名单，需要完整管理能力时使用系统浏览器提供的标准操作。
- [x] URL 构造具有确定性单元测试，两个入口分别具有界面覆盖。

#### SPEC-014：设备仪表盘

**优先级：** Must
**状态：** Approved

App 应在连接 FMO 后，用类型化状态快照驱动设备页仪表盘。原型以 0.3 已确认的字段语义为准；正式 App 按字段渐进接入，只有具备公开文档、接口所有者明确授权或经 ADR 批准来源的字段才可开发为可用状态。原型示例值和抓包观察本身不得作为 Release 授权的证明。实时活动不属于 0.3 范围，已有 ActivityKit 实现只保留为后续 checkpoint。

**设备页信息：**

- 大字号我的呼号、过滤器距离，以及由 WGS84 坐标派生的六位梅登黑德网格；设备页不显示经纬度。
- 当前连接服务器名称；服务器 UID 只用于内部关联。管理员呼号只有取得可靠字段时才条件显示。
- 点击当前服务器名称打开原生服务器选择 Sheet；收藏与全部服务器均在每次打开时从当前设备实时读取，不使用跨会话缓存。收藏分组从打开起固定在顶部并显示加载状态；首批服务器返回后立即展示，后续分页与收藏继续加载；选择其他服务器后只有在设备回读 UID 匹配时才更新卡片并关闭。
- 单行动态事件窗口显示当前讲话呼号、可选网格与最近本地活动；当前讲话优先固定，结束后恢复纵向事件切换。本地事件与 0.4 APRS `VOCAL` 时间线是不同来源。
- 设备选择移至设备页导航栏；连接态卡片原位置提供全屏入口。点击后在同一时刻启动共享元素扩展、左右面板滑入与横屏方向更新，并在旋转结束时共同完成；地图解析、音频等服务等到视觉转场稳定后再启动。设备页已连接时，系统允许的自然横屏旋转也自动触发同一转场；在全屏仪表盘自然转回竖屏时自动退出。旋转锁定或停留在其他 Tab 时不触发。退出时左右面板滑出、共享元素缩回、首页恢复与竖屏方向更新并行，全屏层与深色底层保留到旋转最后一帧再移除。全屏背景可覆盖屏幕边缘，但按钮和信息必须留在横屏安全区内；系统拒绝方向更新时保留可用的自适应布局。
- 横屏全屏仪表盘可见且 App 位于前台时禁用系统自动锁屏；退出全屏、转入后台或页面销毁时恢复进入全屏前的系统值，不影响其他页面的锁屏策略。
- 横屏仪表盘以当前讲话者为目标，在同一主视觉区域内切换方位盘与自动追踪地图。位置优先关联近期、已通过内部准入的 FMO V4/APRS 坐标；无法唯一关联时使用 `/events` 的六位网格中心并明确表达为大致位置，冲突或缺失时不猜测。
- 横屏仪表盘在地名下方持续显示设备接收音频波形，并提供独立声音按钮。每次进入、回到前台或切换设备均默认静音；静音不停止波形，开启声音只播放此后收到的音频。
- 单一工作频率与盒子报告的 QSO 日志数保留在类型化数据层或对应功能页，不投影到设备页仪表盘；不得拆成 TX/RX，也不得把日志数表述为实时通联人数。
- 延迟、服务器管理员呼号和当前/最大在线人数在 0.3 隐藏，取得可靠来源后另行评审。

**验收标准：**

- [x] 设备页完整仪表盘由 `DashboardSnapshot` 投影，字段值、来源、观测时间和过期状态一致。
- [x] 每个字段具有“可用、未知、过期、不支持或已拒绝”的明确状态；单个来源失败只降级相关字段，不把未知值显示成 `0` 或实时数据。
- [x] HTML 原型覆盖 0.3 已确认的信息层级；ADR-0005 白名单字段已进入正式 App，白名单外字段继续不渲染或保持 `unknown / unsupported`。
- [x] Release composition 不注入原型或 Preview 数据提供者；自动测试证明正式路径不存在硬编码示例值或模拟回退。
- [x] “我的呼号”“当前服务器”“过滤距离”和“当前讲话者”只来自 ADR-0005 类型化白名单，不使用 APRS、BEACON、导入 QSO 或 GEO RTT 冒充；数据层保留的频率和 QSO 日志数遵循同一来源边界，但不投影到设备页。
- [x] 过滤原始枚举 `0...7` 分别映射为禁用、50、100、200、500、1000、2000、5000 km；未知值拒绝。
- [x] 梅登黑德网格只由带来源、观测时间的有效 WGS84 坐标派生，并继承坐标的可信度与过期状态。
- [x] 本地 `/events qso/callsign` 只有在事件流健康且状态新鲜时才表述为正在讲话；讲话结束后主位保留最后讲话呼号并以计时图标和灰阶表达已结束，直到下一位开始讲话才进入历史。断流时不得继续表述为正在讲话。可选 grid 缺失只降级位置。
- [x] 本地 `/events qso/history` 只作为最多 20 条近期设备活动，与 APRS `VOCAL`、完整 QSO 数据库分开建模；设备页最多投影最新一条。
- [x] 设备选择按钮位于设备页导航栏并打开统一 Sheet；连接态卡片原位置只提供全屏仪表盘入口，不复用两个动作。
- [x] 首页当前服务器名称整行可点击并打开设备服务器 Sheet；设备收藏与全部服务器分组显示，支持搜索、刷新、行内切换进度、失败重试和当前项标记。
- [x] 服务器目录不使用持久化或跨会话缓存；每次打开先清空旧目录，首个实时分页返回即显示，加载后续分页时保留已返回条目和明确进度，避免因缓存展示已离线服务器。
- [x] 服务器切换只使用 ADR-0010 独立控制客户端，切换成功必须回读当前 UID；切设备、断开或取消会隔离旧结果，不把响应成功直接当成状态成功。
- [x] 首页卡片与全屏仪表盘使用同一根层 Hero 容器和共享元素转场；转场期间不会出现重复卡片、底栏穿透或提前启动全屏音频任务，开启“减少动态效果”时缩短共享元素转场且重内容只淡入淡出。
- [ ] 真机确认横屏全屏期间不会自动锁屏，退出全屏或转入后台后恢复原有自动锁屏行为。
- [ ] 横屏仪表盘覆盖方位/地图切换、系统拒绝旋转、网格缺失、APRS 关联唯一/冲突、位置过期与地图追踪暂停/恢复状态。
- [x] 音频只在 App 活跃且横屏仪表盘可见时连接所选设备；退出、转入后台或切换设备立即停止。音频不录制、不持久化、不上传、不转发，也不用于识别当前讲话者。
- [x] APRS 精细位置只有在基础呼号、网格、当前服务器、观测时间等约束得到唯一候选时才关联；本地事件没有 SSID 时不得任意选择同呼号 APRS 身份。
- [x] 实时活动、锁屏与 Dynamic Island 不在 0.3 用户界面、验收和完成度中出现。
- [x] 不读取官方 Web DOM、不注入脚本；未获公开文档、接口所有者授权或边界 ADR 批准的管理接口不得进入 Release，也不通过 APRS 推断缺失的设备内部实时状态。

### APRS 网络

0.4 采用只读 APRS-IS 边界：使用 `pass -1` 和服务器端过滤接收 FMO V4 报文，不要求用户配置 APRS PASSCODE，也不发送 APRS 数据帧。连接只在 App 活跃期间提供实时数据；后台持续连接、APNs 与通知交付不属于 0.4。标准 APRS 短消息、ACK 与 FMO 公网远控统一留到 0.6。

只读客户端身份由呼号和独立 SSID 组成：用户手动设置的值优先；没有手动值时继承最近一次从用户已选择 FMO 读取到的可信呼号，并使用可编辑的 App SSID。手动覆盖不得因连接或切换 FMO 被静默改写；App 绝不从盒子读取 PASSCODE。

#### SPEC-006：FMO V4 地图与台站目录

**优先级：** Must
**状态：** Approved

App 应展示通过 FMO V4 APRS 获得的用户、BEACON 与 STATION 信息，包括位置、呼号、服务器地址、覆盖范围、在线/峰值人数和数据年龄。

**验收标准：**

- [x] 用户可收藏呼号；呼号按规范化基础呼号去重。公共 FMO 服务器仍可搜索和查看详情，但不在 App 内维护独立收藏。
- [x] 呼号收藏本地持久化并与短期 APRS 缓存分离；刷新、离线、数据过期和 App 重启不会静默移除收藏。设备服务器收藏由所选 FMO 的 ADR-0010 列表提供。
- [x] 取消收藏只移除可逆偏好，不删除目录对象、历史事件、QSO 或信任材料，也不需要危险确认。
- [x] 收藏状态不改变内部验证结果；过期、吊销或无法验证的数据不得因收藏进入业务界面。0.4 暂不向普通用户展示技术信任状态。
- [x] “收藏呼号”作为 0.6 消息页的常用联系人来源，不额外维护一套含糊的联系人收藏；设备服务器收藏与 SPEC-012 自建管理服务器保持不同来源。
- [x] 0.4 无需计算或配置 PASSCODE，仍通过 APRS-IS `pass -1` 只读登录并取得过滤后的 FMO V4 数据；0.4 UI 不出现发送、远控或凭据配置入口。
- [x] 首次取得可信 FMO 呼号后可自动建立只读身份；用户可在设置中编辑呼号与 App SSID，手动值优先且重启后保留。
- [x] 0.4 的 APRS 会话按 `APFMO4` 获取公网广播，不自动继承盒子的距离过滤器；导航栏范围菜单提供全网及 `50 / 100 / 200 / 500 / 1000 / 2000 / 5000 km` 本地展示范围，默认 `500 km`。有限范围以手机最近一次主动取得的位置为中心，同时裁剪地图、动态和目录，但不改变 APRS-IS 订阅或写入 FMO。
- [x] 地图默认随新台站更新相机，用户可用左下角“追踪”开关暂停；右下角“我的位置”按钮使用使用期间授权获取一次位置并更新范围中心。首次进入已配置的 FMO 网络页时为默认 `500 km` 获取一次位置；定位失败则回退全网并提供错误反馈。此后手动选择有限范围时按需请求定位，失败则继续使用原范围。
- [x] FMO 网络页最近动态最多展示 3 条；短期事件快照只保留最近 24 小时且最多 200 条，完整事件流应简短显示该保留边界，避免前台长时间接收导致无界增长。

#### SPEC-007：事件时间线（通知延期）

**优先级：** Should
**状态：** Approved

App 应支持 `CQ`、`OMCQ`、`VOCAL`、`ONLINE`、`BEACON`、`STATION` 与 `JOINT + EVENT`，并允许按类型、呼号、距离和收藏过滤。

**验收标准：**

- [x] “收藏”过滤匹配事件主体的收藏呼号；设备服务器收藏不参与公共 APRS 事件筛选。无收藏时显示可行动空状态。
- [x] 完整验证的 `VOCAL` 只生成带呼号、SSID、位置、服务器 UID、观测时间与可信状态的“最近语音活动”事件，不生成“当前通联对象”或“当前说话人”。
- [x] `CQ` / `OMCQ` 只表述为发起呼叫，不推断呼叫目标、接听结果或已建立通联；QSO 历史不进入实时事件状态。
- [x] 语音事件可以用扬声器或对讲机图标压缩可见文案，但必须同时保留呼号、观测时间及可访问性标签；不能只靠颜色表达。
- [x] 多个近期 `VOCAL` 按可信观测时间排序，主界面显示最新一条并保留其他数量或入口；验签失败、重放、乱序旧帧不得覆盖更新的可信事件。
- [x] `VOCAL` 没有结束事件；产品定义的近期展示窗口独立于 `timeSalt` 验证窗口，过期后只能表述为“最后活动于”，不能断言讲话已经结束。
- [x] App 进入非活跃状态时不承诺继续接收事件；0.4 不把本地通知或 APNs 作为事件到达保证。

#### SPEC-008：FMO V4 身份验证

**优先级：** Must
**状态：** Approved

App 应验证 CERT blob、呼号绑定、证书链、证书有效期、Ed25519 消息签名、timeSalt 窗口、JOINT/EVENT 哈希关系和可用 CRL。

**验收标准：**

- [x] 无法验证、已明确吊销或签名失败的数据不得进入地图、目录和事件等业务界面。
- [x] 过期、吊销、签名错误、呼号不匹配和未知根继续使用不同的内部类型化状态，但 0.4 UI 暂不展示技术验证标签、CRL 新鲜度或验证详情。
- [x] 不通过降低验证强度来兼容错误报文。

#### SPEC-009：APRS 短消息

**优先级：** Should
**状态：** Complete

用户配置自己的呼号和 SSID 后，App 在前台活跃期间发送、接收标准 APRS 消息与 ACK。消息使用 App 独立的 `呼号-SSID` 身份；呼号可继承最近一次可信 FMO 呼号，手动身份始终优先且不因设备切换被覆盖。APRS-IS PASSCODE 由规范化基础呼号本地确定性计算，SSID 不参与；用户无需输入，App 不持久化计算值。

**验收标准：**

- [x] 收件人可从收藏呼号选择，也可手动输入完整 `呼号-SSID`；发送前始终显示实际收件地址，收藏数据不复制为第二套联系人。
- [x] 消息会话与历史仅持久化在本机，App 重启后仍可查看；不上传、不云同步、不自动清理，支持系统左滑删除且只删除本地会话历史。
- [x] 用户可区分发送中、等待 ACK、已确认和未确认；ACK 必须同时匹配对端身份与消息 ID，不能按文本或时间接近误关联。
- [x] 普通消息首次发送后最多自动重试 2 次；进入后台、身份变化或达到上限时停止，回到前台不自动补发旧消息，只允许用户手动重试。
- [x] 重复消息在历史中只保存和展示一次；若报文要求 ACK，每次重复到达仍安全回复 ACK。
- [x] 离线时允许保留草稿，但不创建离线待发送队列；连接中断使等待中的消息变为“未确认”，不得断言对方一定没有收到。
- [x] APRS 身份 Sheet 只包含呼号和 SSID，不出现“消息设置”、PASSCODE 输入或第二层 Sheet。
- [x] 基础呼号忽略大小写并去除 `-SSID` 后计算 PASSCODE；任意 SSID 变化不改变结果，基础呼号变化会重新计算并重建写会话，算法以公开已知向量验证。
- [x] PASSCODE 仅在建立可发送 APRS-IS 会话时按需计算，不写入 Keychain、UserDefaults、SwiftData、日志或诊断；服务端拒绝发送登录时，只读 FMO 网络继续可用，消息提供身份检查入口。
- [x] 0.6 不承诺后台常驻、离线消息到达、APNs 或服务端推送。

#### SPEC-010：FMO 远程控制

**优先级：** Must
**状态：** Complete

App 应按固定版本的官方格式生成 `NORMAL`、`STANDBY`、`REBOOT`，实现 Time Slot、Counter、HMAC-SHA1 截断签名和 ACK 等待。远控目标为设备页当前或用户此前可信保存的 FMO 身份，SECRET 按目标设备隔离保存。

**验收标准：**

- [x] 远控 SECRET 只存入 Keychain，可按目标设备独立更新和清除，不写入日志、普通偏好、消息历史、诊断导出或服务器；计算出的 APRS-IS PASSCODE 不持久化。
- [x] 远控入口和按目标设备隔离的 SECRET 设置只位于“设备”；FMO 网络不展示设备远控入口或 SECRET 表单。
- [x] `NORMAL` 与 `STANDBY` 使用明确的单次发送操作；`REBOOT` 先展示危险影响，再经过 LocalAuthentication 二次确认。认证取消或失败时不得生成或发送命令。
- [x] Counter 在同一 Time Slot 内单调递增并原子持久化，签名前预留且发送失败后不回滚，避免 App 重启或崩溃后复用。
- [x] 远控命令不自动重试；ACK 超时显示“未确认，设备可能已经执行”，由用户决定是否手动重试。
- [x] 缺少可信目标身份、目标 SECRET 或可发送 APRS-IS 会话时禁用远控发送，并提供对应配置路径。
- [x] 普通界面只展示目标设备、操作影响、发送进度与 ACK 结果，不展示 Time Slot、Counter、HMAC 或 Keychain 等实现细节。
- [x] 远控只使用公开 APRS-IS 格式，不复用局域网 `/ws` 未公开配置写命令，也不扩展到三种命令以外的控制。

### QSO 与服务器

#### SPEC-011：QSO 自动同步、查询与 ADIF

**优先级：** Should
**状态：** Approved

App 应在用户所选 FMO 可达时，通过 ADR-0007 固定的本地只读 QSO 白名单自动同步通联日志，支持离线缓存、查询、网格地图、详情与 ADIF 导出。日常浏览不得要求用户下载 SQLite、签名文件或完成手动导入。

**验收标准：**

- [ ] 连接或切换 FMO、App 进入前台、打开 QSO 页面时自动刷新所选设备；页面可见期间低频检查变化，并提供手动刷新。App 不宣称后台实时或固定周期同步。
- [ ] 首次同步分页取得全部摘要并尽快展示；最近记录可优先补齐详情，旧记录详情在打开或导出时可取消地串行读取。单条错误不阻塞已成功记录。
- [ ] 缓存按设备稳定身份隔离，以 `设备 + logId` 去重；只有完整分页同步成功后才执行删除对账，部分失败或断线不得清空既有记录。
- [ ] FMO 离线时显示该设备最后一次成功同步的内容和时间；没有设备、从未同步、同步中、空日志、部分失败和完全失败均有不同且可行动的状态。
- [ ] 列表和搜索使用真实摘要字段；详情只展示接口实际提供的双方呼号/网格、时间、频率、模式、服务器、管理员和备注，不虚构通联时长、精确坐标或信任结果。
- [ ] 网格地图只表达 Maidenhead 网格的大致区域，不冒充精确轨迹；网格缺失时详情其余内容继续可用。
- [ ] ADIF 从已同步且已补齐的规范化记录生成；缺失详情时先显示可取消进度，导出包含标准字段并可选保留 `APP_FMO_*` 扩展。
- [ ] 普通界面不显示“已验证/待检查”、SHA-256、P-256 或 WebSocket 等技术状态。自动同步记录只表述为来自用户所选 FMO。
- [ ] 客户端只实现 `qso/getList` 和 `qso/getDetail`，不实现备份、恢复、清空、签名/公钥、密钥重置、设备端 ADIF 生成或任意命令代理。

#### SPEC-012：自建服务器运维

**优先级：** Could
**状态：** Approved

App 应通过独立 HTTPS API 查看自建服务器的 DNS、MQTT 可达性、EMQX/SAS 状态、连接数、资源使用、广播状态和脱敏日志。写操作必须单独授权并二次确认。

#### SPEC-013：iOS 系统集成

**优先级：** Could
**状态：** Approved

支持 APNs、本地通知、桌面小组件、Siri 快捷指令、深色模式、动态字体和 VoiceOver。实时活动与普通锁屏小组件均属于 0.3 之后另行评审的系统集成范围。

## 明确排除

- 解码或收发 FMO MQTT 语音。
- 录制、保存、上传、转发或后台持续播放 FMO 本地接收音频，以及从音频内容推断讲话者。
- 模拟盒子登录 MQTT。
- 获取、导出、复制或使用盒子私钥。
- 除 ADR-0010 固定白名单外，逆向或代理未公开的盒子配置、服务器切换、收藏写入、音量、频率、编码器或 OTA 接口。
- App 内完成官方设备激活或证书签发。
- 将 iPhone 个人热点拓扑列为保证能力，除非实机验证通过。
- 0.6 的后台 APRS-IS 常驻、离线消息保证、APNs、通知服务端、云端消息存档和跨设备历史。
- APRS 群聊、广播消息、附件、图片、音频、已读回执和在线状态推断。
- 0.8 的 QSO 删除/恢复、自动触发数据库备份、签名密钥管理、后台持续同步和跨设备云同步。
