# ADR-0003：最低部署版本采用 iOS 26

**日期：** 2026-08-03

## 背景

FMO Companion 是从零开始的原生 iOS 项目，目前没有需要继续支持的既有用户或旧版本安装。项目面向配合 FMO 盒子使用的联网手机，产品方向更重视较新的系统能力、简洁的实现和较小的兼容性测试矩阵，而不是覆盖长期不升级系统的设备。

## 决策

- App、单元测试和 UI 测试 Target 的最低部署版本统一设为 iOS 26.0。
- 产品代码可以直接采用 iOS 26 API。
- 不为 iOS 18 及更早版本添加 availability 分支、兼容垫片或单独测试矩阵。
- 如果未来需要扩大旧设备覆盖，应以新的产品数据和用户需求重新评估，并用后续 ADR 取代本决策。

## 结果

### 正面影响

- 减少条件分支和旧系统行为差异，降低开发、测试与维护成本。
- 可以优先采用当前 SwiftUI、并发和系统框架能力。
- Simulator 与真机测试矩阵更集中。

### 负面影响

- 停留在 iOS 18 或更早版本的设备无法安装 App。
- 即使硬件能够升级到 iOS 26，拒绝升级系统的用户也不在支持范围内。
- 如未来下调最低版本，需要重新审查已使用 API，并补充兼容实现与测试。
