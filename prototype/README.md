# FMO Companion HTML 原型

这是正式 SwiftUI 开发前的交互与视觉验证稿。原型不访问真实 FMO、局域网、位置或凭据，所有设备、呼号、坐标、消息和服务器状态都是虚构示例。

## 打开方式

在仓库根目录执行：

```bash
python3 -m http.server 4173 -d prototype
```

然后访问 `http://127.0.0.1:4173/`。

仪表盘卡片的独立设计页位于 `http://127.0.0.1:4173/dashboard-card.html`。该页面已收敛为“我的 FMO、当前服务器、单行动态事件”三个内容区域：只显示大字号呼号、六位梅登黑德、过滤距离、服务器名称和本地活动；QSO 数与单一频率不进入首页卡。确认稿已同步到主 HTML 原型，SwiftUI 实现仍待下一步收敛。

## 可评审内容

- 页面只展示接近最终 App 的用户界面，不包含规格跳转、里程碑或评审工具。
- App 打开后自动发现并连接首台示例设备；首台失败不顺延。首页可演示手动地址、设备列表切换、连接后设备仪表盘、坐标同步、诊断和设备远控，卡片不提供主动断开操作。
- 连接成功后，首页顶部卡片目标为大字号呼号、当前服务器、过滤距离、六位梅登黑德与单行本地当前讲话/近期活动；QSO 数和单一频率不进入首页卡，延迟、无可靠来源的管理员和在线/最大人数隐藏。
- 锁屏仪表盘不占用首页卡片空间；其精简布局与呼号、事件、位置类信息的显示偏好统一从设置进入。
- 底部标签可进入网络、通讯、QSO 与系统集成的代表性功能流程。
- 用户层底部只保留首页、FMO 网络、QSO、设置四个标签。
- 危险远控会显示二次确认，但不会发送任何命令。
- FMO 网络页包含台站目录、事件流、消息和按需展开的身份验证详情。
- 台站目录可分别收藏呼号和公共服务器，并在“收藏”页签中统一查看；语音事件用扬声器图标表达“最近检测到语音活动”，不冒充实时通联状态。
- QSO 页包含导入验证、查询详情和 ADIF 导出。
- 设置页包含管理员功能、通知、锁屏仪表盘、快捷指令、隐私无障碍与产品边界。

仪表盘固定数值与活动切换仍是虚构原型数据，只用于验证 0.3 已确认的信息层级。用户设备抓包观察到的管理 WebSocket 字段在正式文档、接口所有者授权或边界 ADR 完成前不进入 Release；不得从原型反推数据已经获准，也不得使用替代数据补齐。

设计规则见 `docs/design/ui-design-system.md`，规格映射见 `docs/design/prototype-coverage-matrix.md`，后续 AI 开发必须读取 `docs/design/prototype-implementation-guide.md`。
