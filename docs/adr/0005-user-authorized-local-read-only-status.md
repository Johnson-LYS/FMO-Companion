# 0005：采用用户授权的本地只读状态接口

**日期：** 2026-08-05

**状态：** Accepted；`/audio` 排除条款由 ADR-0009、服务器切换排除条款由 ADR-0010 作有限修订

**修订：** ADR-0001 的公开协议边界

## 背景

FMO 官方设备 Web UI 会通过同一设备上的 `/ws` 与 `/events` 展示呼号、当前服务器、过滤距离、工作频率、QSO 日志数和本地讲话活动，但截至 2026-08-05 没有找到这些管理消息的公开版本、鉴权和错误契约。用户分析了本人设备、本人有权访问的后台流量，并明确授权 App 在其选择的 FMO 上使用这些本地状态能力完成 0.3 仪表盘。

同一 `/ws` 还存在 PASSCODE 读取、配置写入、服务器切换和重启等能力；`/audio` 则承载未公开语音数据。若实现通用命令代理、保留原始帧或把未知字段写入日志，会突破 ADR-0001 的安全意图。

## 考虑的方案

1. **继续只使用公开 GEO：** 风险最低，但 0.3 无法提供用户已确认的核心设备仪表盘。
2. **严格白名单的用户授权只读状态：** 只实现已确认语义的最小请求和事件，未知内容丢弃并失败关闭。
3. **复用完整 Web 管理协议：** 能力最全，但会暴露秘密、写操作和未授权语音边界，不可接受。

## 决策

采用方案 2，并以本 ADR 对 ADR-0001 作有限修订。Release 可以访问用户主动选择且有权管理的 FMO 本地接口，但只能实现以下固定能力：

- `/ws`：`user/getInfo`、`station/getCurrent`、`config/getServerFilter`、`config/getUserPhyFreq`、`qso/getList`。
- `/events`：`qso/callsign` 与 `qso/history`。
- `qso/getList` 只请求第 0 页、每页 20 条，并只读取响应的 `count`；App 不借此导入或保存 QSO 内容。

实现必须同时满足以下约束：

- 客户端只暴露类型化只读方法，不提供任意 `type/subType` 发送入口。
- 绝不请求或解析 `getPasscode`；本状态客户端不实现配置写入、服务器切换、服务重启、广播和其他管理命令。ADR-0010 批准的服务器切换必须留在独立控制客户端。
- `/audio` 仍永久排除在本状态客户端之外；ADR-0009 另行批准的独立、前台、只接收 PCM 客户端不得复用或扩大本白名单。
- 解码器只声明业务所需字段，未知字段直接丢弃；不得记录原始 WebSocket 帧、精确坐标、真实呼号、端点或潜在秘密。
- 真实抓包不进入仓库。测试只使用人工构造、最小化且完全脱敏的协议向量。
- `/ws` 没有请求 ID，因此命令串行发送；切换设备或重连后丢弃旧会话结果并重新拉取完整状态。
- 任一命令、字段或事件不符合白名单 schema 时失败关闭，只降级对应仪表盘字段，不影响 GEO 等其他独立来源。
- 该接口按“用户授权、未版本化的本地只读契约”维护；固件变化造成不兼容时隐藏相关信息，不放宽校验或转向 DOM/音频抓取。

## 后果

### 正面

- 0.3 可以用真实设备数据实现已确认的首页与锁屏信息层级。
- 类型化白名单阻断 PASSCODE、写命令和音频能力被意外带入 App。
- 各字段独立降级，未版本化接口故障不会破坏 GEO 连接与坐标同步。

### 负面

- 接口没有正式版本契约，固件升级可能需要维护解析器并重新真机验收。
- 当前样本尚未覆盖无服务器、离线恢复、`isHost` 和设备重启后的事件序列，相关语义继续延期。

### 中性

- 本决策不授权运行时抓包、网页 DOM 注入或完整管理后台复刻。
- 若未来发布正式 API，以正式契约为准，并通过新 ADR 评估是否替换本地观察契约。
