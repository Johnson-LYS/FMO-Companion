# 0010：采用用户授权的本地服务器切换

**日期：** 2026-08-14

**状态：** Accepted

**修订：** ADR-0001 与 ADR-0005 的服务器切换排除条款

## 背景

设备首页已经通过 ADR-0005 的只读状态会话显示当前服务器，但用户仍需打开 FMO 官方后台才能切换。用户希望点击首页当前服务器名称后，直接查看当前设备可用的全部服务器与设备自身的收藏服务器，并完成切换；App 原有的公共 APRS 服务器收藏不再作为产品能力。

用户在本人有权管理的 FMO 上确认了官方后台的最小固定流程：`station/getListRange` 分页读取设备可选服务器、`station/getPinnedList` 分页读取设备收藏、`station/setCurrent { uid }` 请求切换，并以 `station/getCurrent` 回读确认。该本地协议仍没有公开版本、鉴权或错误契约，因此不能扩展为通用管理客户端。

## 考虑的方案

1. **继续只显示当前服务器：** 边界最简单，但核心设备管理流程仍需离开 App。
2. **独立、严格白名单的服务器选择客户端：** 只读取设备目录/收藏并按已读取 UID 切换，写后回读确认。
3. **复用只读状态客户端或实现通用后台代理：** 开发量较小，但会污染 ADR-0005 只读边界，并可能意外开放秘密、配置和其他管理命令。

## 决策

采用方案 2，并对 ADR-0001/0005 作有限修订：

- 独立 `FmoStationControlWebSocketClient` 只能发送 `station/getListRange`、`station/getPinnedList`、`station/getCurrent` 与 `station/setCurrent`。
- 客户端不得提供任意 `type/subType` 入口，不实现 `next/prev`、收藏/取消收藏、PASSCODE、频率、音量、OTA、备份、恢复、重启或其他配置命令。
- “收藏服务器”只指当前 FMO 设备通过 `getPinnedList` 返回的收藏；App 不创建、写入或合并独立的服务器收藏。
- `setCurrent` 只接受本次设备目录或设备收藏中出现过的正整数 UID。收到成功响应后必须再次调用 `getCurrent`，且 UID 与目标一致才向 UI 报告成功。
- 控制客户端使用独立 WebSocket 会话并由 Actor 严格串行请求，不能复用每 3 秒刷新的 ADR-0005 状态会话。切换设备、断开或取消界面任务时关闭旧控制会话，旧结果不得写入新设备。
- 分页、单帧、UID、名称和最大总数均设置固定上限；未知字段丢弃，路由、类型、计数或结果不符合固定 schema 时失败关闭。
- 服务器选择器不持久化目录或收藏列表；每次打开和手动刷新都从当前设备建立实时控制会话。`getListRange` 每页校验成功后立即向 UI 追加展示，后续页和 `getPinnedList` 继续串行读取，不能为了首屏速度展示上次会话缓存或临时 IP 关联的数据。
- 不记录原始帧、设备端点、真实服务器选择历史或潜在秘密；真实抓包不进入仓库，测试只使用人工脱敏向量。
- 固件不兼容时保留当前服务器只读展示并降级选择器，不扩大白名单或转向网页注入。

## 后果

### 正面

- 用户可在设备首页完成服务器浏览与切换，并与盒子官方收藏保持同一来源。
- 写能力被隔离在单一、可审计的 UID 切换操作中，不改变 ADR-0005 状态客户端的只读性质。
- 写后回读避免成功响应与设备真实状态不一致时产生乐观 UI。

### 负面

- 未版本化接口可能随固件变化，需要真机回归；失败时只能降级而不能自动兼容。
- 当前没有批准设备收藏写接口，因此 App 只能展示设备收藏，收藏管理仍由设备官方后台完成。
- 公共 FMO 网络不再提供服务器收藏；旧 `FavoriteServer` 存储类型只为已有 SwiftData 数据兼容而暂留。

### 中性

- 本决策不改变 APRS 公网远控、FMO 网络服务器目录、自建服务器管理或设备 GEO 坐标同步。
- 当前服务器仍由 ADR-0005 低频只读刷新观察外部变化；选择器控制会话只在用户打开或执行切换时使用。
